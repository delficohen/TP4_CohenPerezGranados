## Descripción del trabajo

Se diseñó la base de datos de un centro médico (pacientes, médicos, consultas y recetas) y se resolvieron 20 consultas en SQL sobre una base ya armada, usando PostgreSQL.

## Qué hay en el repo

- `NN_InfoMed_TP4_CohenPerezGranados.sql`: la query de cada consigna de SQL, donde `NN` es el número de consigna.
- `InfoMed_TP4_CohenPerezGranados.md`: la resolución completa de las partes 1 y 2, con cada query y una captura de su resultado.
- Las consignas 16 a 20 están en un pull request abierto, en la rama `students/CohenPerezGranados/TP4_16_17_18_19_20`.
